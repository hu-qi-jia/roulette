# 知识库检索在宿主侧

## Status

accepted

## Context

v1.1 要加入个人知识库：本地 embedding、本地向量库、导入文档后检索。如果让每个引擎自己实现检索，知识库会被耦合到不同 harness/API 的差异上，也无法保证隐私提示和引用格式一致。

## Decision

宿主负责 embedding、检索和上下文拼装；`Engine` 只接收 messages（和可选的图片）。知识库对引擎不可见。

## Consequences

- 引擎保持"消息进、文本出"，可替换。
- 知识库可以独立演进，包括未来切换到远程向量库。
- 引用、相似度阈值、隐私提示由宿主统一控制。
- 接入 CLI 任务模式时，检索仍然在宿主侧。
